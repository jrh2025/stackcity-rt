# 《StackCity RT（像素疊界）》

結合 **CityRT 即時微縮城市互動體驗** 與 **Sprite-Stacking（精靈堆疊）偽 3D 像素體素造物技術** 的單一執行檔創意導演沙盒（Rust + SQLite + WebGL2）。

## 核心特色

1. **純 Rust Sprite-Stacking 造物工坊（零 Python 依賴）**
   - 內建 6 大類 **68 種**可編輯藍圖原型（建築地標、人物角色、動物生態、植物景觀、交通載具、家具道具）。
   - 支援繁體中文／英文語意描述即時生成（如「雪中的金色城堡」、「發光的紫色櫻花樹」）。
   - 內建 **3D 積木藍圖細部編輯器**：可微調畫布尺寸、每塊積木位置（X/Y/Z）、長寬高（W/D/H）、半徑、10 種材質、夜間發光、X 軸鏡像，並區分**純記憶體預覽（未確認不存庫）**與**確認儲存／覆寫**。
   - 支援**個人跨世界資產庫**與**本世界資產庫**之改名、分類編輯、細調覆寫與刪除；完整相容 `.zip` 套件、`blueprint.json`、`slices.png` 與四視圖 PNG 視覺外殼雕刻（Visual-Hull Carving）。
   - 支援外部 **AI 藍圖建模**（Google **Gemma 4**、Google **Gemini 2.5 / 3**、**OpenAI 相容端點**），提供自由輸入模型名稱、一鍵查詢帳號可用模型清單，以及 API Key 本機記憶與移除功能。

2. **WebGL2 GPU Instanced 3D 微縮渲染引擎**
   - 每層精靈切片採三疊微厚度設計，搭配硬體 Z-Buffer 深度測試、地面陰影與旋轉 OBB 防穿牆／防落水物理碰撞。
   - 支援 24 小時日夜光影流轉與天氣（晴／雨／雪，下雪時朝上表面自動覆雪；夜晚自動點亮 `emissive.png` 窗燈、車燈、街燈與水晶）。
   - 支援自訂專屬**玩家角色（Avatar）**，於上帝微縮視角或 **CityRT 街道漫步模式（Street Walk）** 中用 WASD／方向鍵自由探索、跳躍與按 `F`／點擊互動。

3. **無程式碼活體事件導演、12 大預設場景與過關任務引擎**
   - 內建 **6 大戶外場景＋6 大建築內部剖面場景**（奇幻王國、霓虹都會、陽光農莊、櫻花校園、海港小鎮、自由島嶼、皇家宮殿、商店、工廠、辦公室、教室、住家），支援場景擴展、重新命名與快照還原。
   - **三軸尺寸與路徑／事件導演**：支持獨立 X/Y/Z 縮放（含等比例鎖定）、路徑巡航、自由漫遊區、乘載解除附掛、物件相遇事件與選擇題／線索／搶劫／支援／寶藏／嫌疑犯指認過關系統。
   - 內建 5 種截然不同的多軌程序化配樂，亦可上傳自訂音樂封裝進世界檔。

4. **雙模式好友分享與多語系支援**
   - **完整分享（`.stackworld.db`）**：透過 SQLite `VACUUM INTO` 將所有貼圖 BLOB、藍圖、地形、實體、路徑、事件與音樂打包在單一檔案內，好友匯入後可參觀亦可繼續編輯擴建。
   - **單純遊戲分享（獨立 `.html` 網頁檔）**：匯出完全離線可玩的純玩家版單一網頁檔，鎖定編輯功能且支援換造型、漫步、任務與音樂。
   - **多語系介面**：內建 **繁體中文**、**English**、**日本語** 自動偵測與即時無損切換。

## 快速啟動

```powershell
# 執行自動化整合測試
cargo test

# 編譯單檔執行檔（內嵌完整前端資源）
cargo build --release

# 啟動伺服器（自動開啟瀏覽器）
.\target\release\stackcity-rt.exe --data-dir .\worlds
```

Windows 使用者亦可在編譯後直接雙擊 [start_stackcity.bat](./start_stackcity.bat) 啟動。
