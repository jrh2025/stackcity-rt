## 核心特色

1. **純 Rust Sprite-Stacking 造物工坊（零 Python 依賴）**
   - 內建 6 大類 **76 種**可編輯藍圖原型（新增皇家馬車、古典木門、星光傳送門、粉領女上班族、公車站牌候車亭、精品咖啡茶水吧、多功能事務印表機、浴室洗手台鏡櫃）。
   - 支援繁體中文／英文語意描述即時生成（如「雪中的金色城堡」、「發光的紫色櫻花樹」）。
   - 內建 **3D 積木藍圖細部編輯器**：可微調畫布尺寸、每塊積木位置（X/Y/Z）、長寬高（W/D/H）、半徑、10 種材質、夜間發光、X 軸鏡像，並區分**純記憶體預覽（未確認不存庫）**與**確認儲存／覆寫**。
   - 支援**個人跨世界資產庫**與**本世界資產庫**之改名、分類編輯、細調覆寫與刪除；完整相容 `.zip` 套件、`blueprint.json`、`slices.png` 與四視圖 PNG 視覺外殼雕刻（Visual-Hull Carving）。
   - 支援外部 **AI 藍圖建模**（Google **Gemma 4**、Google **Gemini 2.5 / 3**、**OpenAI 相容端點**），提供自由輸入模型名稱、一鍵查詢帳號可用模型清單，以及 API Key 本機記憶與移除功能。

2. **交通工具搭乘系統（自駕／騎乘／自動巡航大眾運輸）**
   - 靠近汽車、皇家馬車、駿馬、公車、火車、帆船、熱氣球或太空船按下 **`G`** 鍵即可上／下車（船／馬），完整保留 **`F`** 鍵給任務互動與開關門。
   - 支援 **「玩家親自駕駛／騎乘」**（水上帆船、空中 `Space`/`Shift` 升降、陸地跑車／馬匹跳躍與鳴笛）與 **「自動巡航乘客」** 雙模式，搭乘公車／火車／渡輪時可隨時按 **`Tab`** 切換。

3. **建築物「門」與跨世界探索系統**
   - 任何建築物、古典木門或星光傳送門皆可開啟 **門（`portal`）** 設定，提供 **「✨ 一鍵建立並連結全新室內世界（自動放回程門）」**。
   - 玩家按 **`F`** 或點擊發光門墊即可觸發淡出轉場進入建築物內部世界探索破關，並在門鎖上鎖時支援指定通行道具／任務旗標檢查。
   - 跨世界冒險進度共享：積分、血量／護盾、持有道具、線索筆記與任務旗標跨世界即時攜帶並同步。

4. **WebGL2 GPU Instanced 3D 渲染、12 大場景與《社畜的一天》5 世界企劃**
   - 每層精靈切片採三疊微厚度設計，搭配 24 小時日夜光影流轉、晴／雨／雪天氣、地面陰影與旋轉 OBB 防穿牆／防落水物理碰撞。
   - 內建 **6 大戶外＋6 大建築內部場景**，並於「＋ 新建世界」提供精選 **《社畜的一天》5 世界聯動完整企劃**（粉領女上班族主角：溫馨住家 ↔ 208 號固定路線公車都市大道 ↔ 公司辦公室 ↔ 生活大賣場 ↔ 療癒美食餐廳）。
   - 支援三軸尺寸、巡航路徑、漫遊區、事件導演、5 種程序化配樂與 6 種過關互動考驗系統。

5. **三模式好友分享與多語系支援**
   - **單一世界完整分享（`.stackworld.db`）**：SQLite `VACUUM INTO` 原子封裝貼圖、藍圖、地形、實體、路徑、事件與音樂。
   - **多世界編輯包分享（`.stackpack.zip`）**：自動 BFS 遞迴掃描門連結打包全部關聯世界；匯入時自動重新指派全新 World UUID 並重寫所有雙向門連結。
   - **跨世界單純遊戲網頁（獨立 `.html`）**：自動打包全部關聯世界與 SHA-256 去重貼圖，鎖定編輯功能，雙擊即玩。
   - **多語系介面**：內建 **繁體中文**、**English**、**日本語** 自動偵測與即時無損切換。

## 快速啟動

```powershell
# 執行自動化整合測試
cargo test

# 編譯單檔執行檔（內嵌完整前端資源）
cargo build --release

# 啟動伺服器（自動開啟瀏覽器）
.\target\release\stackcity-rt.exe --data-dir .\worlds
```

Windows 使用者亦可在編譯後直接雙擊 [start_stackcity.bat](./start_stackcity.bat) 啟動。
