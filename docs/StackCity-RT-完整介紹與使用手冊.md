## 1. 設計理念（Design Philosophy）

《**StackCity RT（像素疊界）**》的誕生源自四個核心設計信念：

1. **「人人皆可造物」的低門檻 3D 創作體驗**  
   傳統 3D 建模軟體學習曲線陡峭，往往讓懷抱故事想法的老師、學生與業餘創作者卻步。本系統將復古迷人的 **Sprite-Stacking（精靈堆疊）** 技術帶入現代瀏覽器 WebGL2：只需要一句中文描述、調整幾塊 3D 積木、貼上一張四視圖、甚至呼叫 AI 協助，就能由內建 **純 Rust 體素引擎** 即時烘焙出可 360° 旋轉、帶法線光影與夜間自發光的立體像素物件。
2. **「從單一地圖走向交通搭乘與推門跨世界探索」**  
   打造王國、都會、農莊或社區不只是靜態擺設：玩家可以按 **`G`** 鍵親手駕駛跑車、騎乘駿馬、乘皇家馬車、划帆船或搭乘固定路線公車通勤；更可以走到任何建築物門口按 **`F`** 鍵推門進入完全獨立的建築內部世界，並帶著跨世界共用的道具、線索與積分出來繼續旅程。
3. **「免寫程式就能製作完整過關遊戲與生活模擬」**  
   透過巡航路徑、漫遊圈、乘載附掛、活體事件與 6 種任務互動考驗，創作者不寫一行程式就能搭出解謎、偵探推理、課堂測驗或《社畜的一天》這類多據點生活冒險遊戲。
4. **「零依賴、單檔即走、多世界一鍵分享哲學」**  
   - 執行主程式僅需單一 `stackcity-rt.exe`（免安裝 Rust / Python / Node / DB）。
   - 單一世界為自包含 `.stackworld.db`；若有多個「門」互相連結的世界，系統自動以 BFS 掃描全圖，支援匯出 **`.stackpack.zip` 多世界編輯包** 與 **跨世界獨立 `.html` 純遊戲網頁檔**。

## 2. 軟體核心特色總覽

### 2.1 純 Rust Sprite-Stacking 造物工坊（零外部依賴）
- **快速文字造物與 76 種內建原型**：涵蓋建築地標、人物角色（含 `粉領女上班族`）、動物生態、植物景觀、交通載具（含 `皇家馬車`）、街道設施（含 `公車站牌候車亭`、`精品咖啡茶水吧`）與室內家具道具（含 `古典木門`、`星光傳送門`、`多功能事務印表機`、`浴室洗手台鏡櫃`）等 **6 大類共 76 種原型**，支援中英文語意修飾。
- **3D 積木藍圖細部編輯器**：支援畫布尺寸、`X/Y/Z` 與 `W/D/H`、8 種幾何原語、10 種材質、夜間發光與 X 軸鏡像，並區分**純記憶體預覽（未確認不存庫）**與**確認儲存／覆寫**。
- **四視圖視覺外殼雕刻與套件匯入**：上傳單張四視圖（TOP / SIDE / FRONT / BACK）即可自動雕出 3D 堆疊模型，亦相容匯入 `.zip` 套件、`blueprint.json` 與 `slices.png`。
- **外部 AI 藍圖建模（可選）**：支援 Google **Gemma 4**、**Gemini 2.5 / 3** 與 **OpenAI 相容端點**，內建 **「🔍 查可用模型」** 與 API Key 本機記憶。

### 2.2 交通工具搭乘系統（`G` 上下車・`Tab` 切換駕駛／巡航）
- **支援陸、水、空多元載具與坐騎**：復古跑車、城市巴士、皇家馬車、蒸汽火車、草原駿馬、航海帆船、彩虹熱氣球與星際飛船皆可互動搭乘；任何自創載具亦可透過右欄 `🚗 交通工具搭乘設定` 啟用。
- **雙重控制模式**：
  - **🎮 玩家親自駕駛／騎乘 (`drive`)**：WASD 控制載具速度與轉向，陸上汽車／巴士按 `Space` 鳴笛、馬匹按 `Space` 跳躍、水上帆船於水域自由航行、飛行載具支援 `Space` 上升與 `Shift / C` 下降，停靠岸邊後按 `G` 自動尋找安全陸地下車／下船。
  - **🚌 自動巡航乘客 (`passenger`)**：若載具綁有巡航路線（如固定路線 208 號公車），上車後即以乘客身分沿站牌自動巡航，並可按 **`Tab`** 隨時在「親自駕駛」與「自動巡航乘客」間切換（或於屬性面板鎖定為 `both` / `passenger` / `drive`）。

### 2.3 建築物「門（`portal`）」與跨世界探索系統
- **一鍵連結建築物內部世界**：選取場景中任一建築物、古典木門或星光傳送門，在右欄點擊 **「✨ 一鍵建立室內世界並建立雙向門」**，即可直接產生對應室內地圖並於室內南牆自動擺放回程出口門。
- **進門／出門防卡牆與上鎖條件**：門口自動投影發光門墊並顯示 `[F] 🚪` 或 `[F] 🔒` 提示；可設定需持有指定道具（如 `通勤悠遊卡`）或完成旗標才能開門；進門與返回自動使用安全退棧座標，絕不卡牆。
- **跨世界共享進度**：在室內與戶外世界間穿梭時，玩家的 **積分、體力、護盾、持有道具背包、線索筆記、任務旗標與主角化身造型／暱稱** 會即時雙向帶著走。

### 2.4 WebGL2 GPU 渲染、雙視角漫步與活體任務導演
- **WebGL2 Instanced 渲染與日夜天氣**：三疊微厚度切片、法線三階像素光影、地面動態陰影、24 小時日夜切換、晴雨雪與防落水／旋轉 OBB 物理碰撞。
- **雙視角自由探索**：上帝微縮視角 WASD 控角 ＋ **CityRT 街道漫步模式（第三人稱跟隨）**。
- **無程式碼活體導演與 6 大任務互動**：支援三軸縮放、巡航路徑、漫遊圈、乘載附掛、三步驟事件導演，以及積分達標／抓出真兇／尋寶／解謎／綜合清單 5 大目標制。
- **多風格程序化配樂與三語系自動切換**：內建 5 風格配樂＋自訂音樂封裝，繁中 / English / 日本語即時切換。

## 4. 系統安裝、啟動與操作介面導覽

### 4.1 啟動方式

#### A. 直接使用免安裝執行檔（最簡單・Windows）
1. 下載 [stackcity-rt.exe](https://github.com/jrh2025/stackcity-rt/raw/main/releases/stackcity-rt.exe) 至任意可讀寫資料夾（例如 `D:\StackCity\`）。
2. 直接**雙擊執行**（若出現 Windows SmartScreen 保護提醒，點選「**其他資訊 → 仍要執行**」）。
3. 程式會自動建立 `worlds/` 資料夾並初始化預設世界，同時自動以瀏覽器開啟 `http://127.0.0.1:8788`。

#### B. 進階命令列參數（亦支援區網多人共享）
```powershell
# 檢視所有參數說明
.\stackcity-rt.exe --help

# 指定資料夾、自訂連接埠並開放同 Wi-Fi／區網內其他人以瀏覽器連線
.\stackcity-rt.exe --host 0.0.0.0 --port 8788 --data-dir .\worlds

# 伺服器背景運行但不自動跳出瀏覽器
.\stackcity-rt.exe --no-browser
```

#### C. 從原始碼編譯（macOS / Linux / 開發者）
```bash
git clone https://github.com/jrh2025/stackcity-rt.git
cd stackcity-rt
cargo test
cargo build --release
./target/release/stackcity-rt --data-dir ./worlds
```

### 4.2 操作介面四大區塊
1. **頂部全域導覽列**：切換／重新命名世界、新建世界（含《社畜的一天》5 世界企劃）、擴展地圖尺寸、切換「✏️ 編輯模式／👁️ 訪客參觀中」、24h 時光與天氣控制、玩家角色設定、街道漫步、音樂設定、重置／刪除世界、快照、分享、面板收合、語系切換（`繁中 / EN / 日本語`）與全螢幕。
2. **左側造物面板（可收合）**：9 大編輯工具與子選項（含生態筆刷規則設定），以及 **Sprite-Stack 資產庫**（支援分類篩選、直接點擊投放、卡片右上角 `✕` 移除物件，與開啟 **✨ 造物工坊**）。
3. **中央 WebGL2 3D 微縮視口**：即時 3D 場景渲染、左上角世界徽章與視角微調鈕、搭乘載具橫幅（`#mountBanner`）、右側浮動 **任務目標追蹤 HUD（可收合、檢視線索筆記與重置）**、門傳送發光地墊與頭頂互動提示標籤。
4. **右側屬性導演面板（可收合）**：
   - `🎛️ 屬性`：選取物件之座標、三軸尺寸、旋轉、燈光、附掛解除、**🚗 交通工具搭乘設定**、**🚪 建築物出入口（門）設定** 與 **🎯 任務互動／考驗設定**。
   - `〰️ 路徑`：移動路線指派與自由漫遊圈管理。
   - `🎬 事件`：友善三步驟活體事件導演。

## 6. 詳細使用說明（手把手教學）

### 6.1 製作專屬 3D 精靈堆疊物件
1. 點左側 **「✨ 造物工坊」** 開啟工作視窗。
2. **方法 A（快速造物）**：輸入描述（如「發光的藍色水晶塔」）或點擊下方 76 種預設原型標籤，調整切片層數後按下 **「⚡ 生成」**。
3. **方法 B（3D 積木細部調教）**：切換到 **「🧱 3D 積木藍圖」**，調整畫布、積木座標／尺寸、材質與夜光；確認滿意後按下 **「💾 確認儲存至資產庫」**。
4. **方法 C（AI 藍圖生成）**：切換到 **「🤖 AI 藍圖」**，選擇 `Gemma 4`、`Gemini` 或 `OpenAI 相容端點`，填入 API Key（可用 **「🔍 查可用模型」** 查詢支援型號），輸入描述由 AI 設計並烘焙成 3D 資產。

### 6.2 設定交通工具搭乘與固定路線公車
1. 在地圖上投放載具（如 `城市巴士`、`復古跑車`、`皇家馬車`、`航海帆船`、`草原駿馬` 等）。
2. 若想建立固定巡航公車，切換至右欄 **「〰️ 路徑」** 幫巴士畫出閉合道路節點，並可在各站牌節點設定停留秒數（例如 `4.5` 秒）。
3. 選取該載具並展開右欄 **「🚗 交通工具搭乘設定」**：
   - 勾選 **「允許玩家按 G 搭乘」**；
   - **搭乘模式**：選 **「🔄 兩者皆可 (Tab 鍵切換)」** 讓玩家既能坐上車當自動巡航乘客，也能按 `Tab` 自己接手開車；
   - **乘載外觀**：巴士／轎車建議「🚗 密閉車廂 (隱藏玩家)」，騎馬／帆船建議「🐎 開放式騎乘 (顯示玩家)」，可微調 `座位高度` 與 `前後偏移`。

### 6.3 設定建築物「門」與跨世界探索
1. 選取屋外任何建築物（如木屋、小店、摩天樓、城堡）或一扇 `古典木門`／`星光傳送門`。
2. 於右欄展開 **「🚪 建築物出入口（門）設定」**，點擊 **「✨ 一鍵建立室內世界並建立雙向門」**：選擇室內主題（例如辦公室、商店、住家、教室、工廠、宮殿）與新世界名稱，系統會自動產生室內世界並於南牆裝好回程門。
3. 若想製作關卡上鎖機制（例如必須吃完早餐拿 `通勤悠遊卡` 才能出門），可於門設定填入 **「開門條件（道具或旗標）」** 與 **「上鎖提示」**。
4. 測試或分享時，系統會自動把所有透過門相連的世界一起打包！

### 6.4 管理世界與分享給好友
- **重置選項**：點頂部 **「🔄 重置」**，可選「清除遊玩進度（保留場景）」、「回復出廠初始狀態」或「永久刪除此世界」。
- **多世界分享**：點頂部 **「🤝 分享」**，視窗會顯示偵測到的門連結關聯世界數量，並提供三種格式匯出與拖放匯入（支援 `.stackworld.db` 與 `.stackpack.zip` 自動判斷匯入）。

## 8. 多元適用場景與應用方向

1. **生活模擬與都市敘事企劃（如《社畜的一天》）**：  
   結合「固定路線公車通勤」與「住宅／公司／賣場／餐廳室內門穿梭」，打造從早到晚、充滿日常幽默與策略選項的微縮城市互動劇。
2. **中小學與大專課堂遊戲化教學**：  
   教師可建立校園大門連接各科專屬教室（數學教室、成語教室、科學實驗室），學生推門進教室答題後把獎勵徽章帶回校園總榜結算。
3. **互動推理與密室尋寶遊戲**：  
   在戶外街區查訪線索，拿取關鍵道具後解鎖上鎖建築大門，於室內找出證物再回到廣場指認嫌疑犯。
4. **空間佈局與建築內外連貫預演**：  
   讓業主或評審先於街道漫步觀看建築外觀與周邊車流，再按 `F` 鍵直接推門走入室內檢視裝潢與日夜光影。

## 9. 系統技術架構與 SQLite 資料模型

```text
[ 前端瀏覽器（零外部 JS 框架）]
 ├── WebGL2 3D Instanced Sprite-Stacking 渲染引擎 (renderer.js)
 ├── 24h 日夜物理、交通工具搭乘與跨世界門系統 (simulation.js)
 ├── 跨世界共享任務目標與 NPC 考驗引擎 (quest.js)
 ├── Web Audio 5 風格多軌合成與載具／門鎖音效引擎 (audio.js)
 ├── 造物工坊 / 積木 / AI / 事件 / 路徑 / 屬性門＆載具面板 (studio.js, tools.js)
 └── 無損三語系國際化引擎 (i18n.js)
        │  REST JSON / Multipart / Blob PNG / ZIP / HTML
        ▼
[ 後端單一執行檔 (Rust + Axum + rust-embed + tokio) ]
 ├── src/voxel/*  ── 純 Rust 體素畫布、76 種原型烘焙、四視圖雕刻、AI 藍圖介接
 ├── src/api/*    ── 世界 CRUD、一鍵連結室內世界、linked-worlds、pack.zip 與跨世界 HTML 匯出
 └── src/db/*     ── rusqlite (bundled SQLite)、office_day.rs 多世界企劃與 __initial__ 快照保護
```

### 核心 SQLite 資料表設計（單檔 `.stackworld.db`）
- `world_meta`：世界名稱、作者、主題、寬高尺寸、時間／天氣、BGM 風格與音量、玩家設定、`quest_config_json`、`quest_progress_json`、`imported_world` 標記等。
- `terrain_tiles`：每格網格座標 `(x, y)` 之高度（`0..5`）、地貌材質與四向拼接道路／橋樑類型。
- `asset_catalog`：自創／預設物件之名稱、分類、`blueprint_json` 與三張核心 PNG BLOB（`slices_png`、`normals_png`、`emissive_png`）及防重複雜湊 `sha256`。
- `world_entities`：場上實體座標、三軸縮放 (`scale_x/y/z`)、角度、發光／可見狀態、`parent_id` 乘載關係與 `meta_json`（同時保存 `interaction` 任務互動、`vehicle` 載具搭乘設定與 `portal` 建築物門設定）。
- `movement_paths` / `wander_zones` / `event_rules` / `world_snapshots` / `world_bgm`：巡航節點、漫遊區、定時／互動事件、初始／手動快照與自訂音樂 BLOB。
- `_library.db`（跨世界個人資產庫）：自動收錄使用者在各個世界建立或匯入的自創物件，跨世界隨時調用、改名與刪除。

## 10. 常見問題 FAQ 與疑難排解

- **Q1：Windows 下載 `stackcity-rt.exe` 後被 Windows Defender SmartScreen 攔截怎麼辦？**  
  這是因個人開源程式未購買商業 EV 數位簽章所致。點擊彈窗中的 **「其他資訊」→「仍要執行」** 即可安心開啟。建議放入獨立資料夾（如 `D:\StackCity\`）再執行，勿直接在壓縮軟體預覽視窗內雙擊。
- **Q2：為什麼走到《社畜的一天》家門或公車旁不知道按哪個鍵？**  
  畫面會在腳邊自動跳出藍／橘提示標籤：**`[G] 🚌 搭乘巡航`** 用來上下車／船／馬／馬車（上車後按 **`Tab`** 可切換自駕／巡航）；**`[F] 🚪`** 用來進出建築物的門（或與眼前 NPC／家具互動）。
- **Q3：在《社畜的一天》選擇「回復世界初始出廠狀態」會把 5 世界門連結洗掉嗎？**  
  不會！建置《社畜的一天》與匯入 `.stackpack.zip` 時皆會自動建立 `__initial__` 原始狀態快照，點擊「回復出廠初始狀態」時會精準還原原本的門連結、公車路線與全套任務設定。
- **Q4：如何備份整個多世界創作專案或一次傳給好友編輯？**  
  只要於任一座相連世界中開啟 **「🤝 分享 → 📦 下載多世界編輯包（.stackpack.zip）」**，系統即會沿著「門」自動打包全部相連世界與貼圖資源；好友匯入該 `.stackpack.zip` 即可一鍵還原整套多世界專案並繼續擴建。
- **Q5：使用 AI 藍圖時遇到 404 模型不存在錯誤怎麼辦？**  
  請確認供應商切換為 **「Google Gemma 4（開放模型）」** 或 **「Google Gemini」**，填入有效 API Key 後按下 **「🔍 查可用模型」**，系統會即時查詢您金鑰真正支援的模型列表並顯示快捷晶片供一鍵套用。
